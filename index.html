What Trigox does

Trigox creates local triggers for file events or app state changes. You give each trigger a name, choose a trigger type, confirm the target, and select the actions you want to run.

Supported triggers

Folder trigger: Folder Change.

File trigger: File Change.

App triggers: Open App, Close App.

How to create one

1. Enter a trigger name.

2. Pick a trigger type.

3. Confirm the target PID or choose the target folder.

4. Enable one or more actions: Notification, Shell Script, Play Sound, or Webhook.

5. Set the scan interval and spam limit, then create the trigger.

Webhook

The webhook option stores a URL in the trigger config. Use this as a target endpoint contract: accept a JSON POST request and return a 2xx response.

Example endpoint URL:

https://api.example.com/trigox/webhook

Example payload fields:

{
  "triggerName": "Folder Watch",
  "triggerType": "ChangeFile",
  "title": "Trigox alert",
  "message": "A trigger fired",
  "timestamp": "2026-07-09T12:00:00Z"
}

Example curl request:

curl -X POST "https://api.example.com/trigox/webhook" \
  -H "Content-Type: application/json" \
  -d '{
    "triggerName": "Folder Watch",
    "triggerType": "ChangeFile",
    "title": "Trigox alert",
    "message": "A trigger fired"
  }'

Tips

App triggers need a confirmed PID before creation. The active trigger list shows saved triggers, and you can stop or start them from there.
